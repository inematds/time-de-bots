# T3 connection

Use Tasks to connect an existing T3 MCP environment by its address. This edition deliberately does not replace a system-wide T3 service. Follow [T3's installation and outside-agent documentation](https://github.com/pingdotgg/t3code) to set up an environment you control, then authorize the connection in your browser.

Choose a project, model and either a new or existing thread. Submit a self-contained task with clear acceptance criteria. T3 work belongs to its own host and continues independently of the Gratis window. The host must remain available. Follow-ups reuse the saved thread; results return when Gratis reconnects.

T3 permissions, filesystem access, provider authentication and runtime approvals are configured in T3. Gratis does not silently forward its Composio credentials. Deleting a local conversation does not cancel independent T3 work; stop it first through Tasks or T3.
