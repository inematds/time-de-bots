Em resumo

O Time de Bots é um kit gratuito do INEMA que instala um painel de bots no seu computador Linux ou Mac, ou numa VPS (um servidor alugado na internet). Cada bot tem nome, avatar, papel, memória e tarefas agendadas, e você conversa com um de cada vez ou com vários em grupo. As respostas vêm da sua assinatura do Claude ou do Codex, pelo login normal do programa oficial, sem chave de API e sem cobrança por uso. Precisa de Node.js 22 ou mais novo e de uma conta Claude ou ChatGPT com Codex.

O que é

Um app de bots + um kit que instala, confere e liga

O app de bots é um programa de computador (feito em Electron, licença MIT). O kit do INEMA põe esse app para funcionar do jeito certo: instala, roda os testes, abre vários times e monta o modo servidor.

🔑 Só a sua assinatura

O app aceita só o login claude.ai do Claude Code ou o login do Codex. O kit/iniciar.sh tira as chaves de API do ambiente antes de abrir.

🧑‍🤝‍🧑 Bots com papel

Cada bot tem nome, avatar, instruções, memória e tarefas agendadas. Converse com um ou chame vários juntos num grupo.

🗂️ Vários times

Cada instância é um time separado, com bots, conversas e memória próprios. Ex.: um pessoal e um de trabalho na mesma máquina.

Como funciona

Da sua assinatura até o grupo de bots

Você entra na sua conta uma vez, no terminal. O app usa esse login para responder. Os bots ficam no painel, conversam sozinhos ou em grupo e rodam tarefas no horário marcado.

Sua assinatura Claude ou Codex→ Login no terminal (claude / codex login)→ App Time de Bots→ Bots · grupo · agenda

💻 No seu computador

O app abre numa janela, como qualquer programa. Os dados de cada time ficam em ~/.local/share/time-de-bots/<instância>.

🖥️ Numa VPS, por túnel SSH

O servidor cria uma tela virtual e mostra o app no navegador (noVNC), tudo preso em 127.0.0.1. Você abre um túnel SSH do seu computador e acessa em http://localhost:6081/vnc.html. Nenhuma porta fica aberta para a internet.

Pré-requisitos

O que precisa ter antes

O kit/instalar.sh confere tudo isso e avisa o que falta.

Node.js 22+ e npm

Baixe em nodejs.org. Confira a versão:

node --version   # v22 ou mais

Claude Code ou Codex

Uma conta Claude (assinatura) ou ChatGPT com Codex, e o programa oficial instalado. Claude Code: guia de instalação.

npm i -g @openai/codex   # se for usar o Codex

Git

Para baixar o kit e atualizar depois. Na VPS: Ubuntu 24.04 ou mais novo e um usuário comum com sudo (não root).

git --version
Guia de uso · passo a passo

Do zero ao primeiro bot

Comandos reais do kit. Rode no terminal, na pasta do kit. Prefere que o assistente faça por você? Pule para os prompts prontos.

No seu computador

1

Baixe o kit

Clona o repositório e entra na pasta.

git clone https://github.com/inematds/time-de-bots.git && cd time-de-bots
2

Instale e rode os testes

Confere Node e npm, instala as dependências, baixa os arquivos do app (conferidos por checksum) e roda os 193 testes. Não entra em conta nenhuma.

kit/instalar.sh   # no fim: "[ok]  193 testes passaram"
3

Entre na sua conta (uma vez)

Você mesmo faz o login no terminal. O comando claude abre o Claude Code: na primeira vez ele pede para entrar na sua conta; depois de entrar, saia com /exit. Ainda não tem o Claude Code? Veja o guia de instalação. Use um dos dois:

claude         # entre com a sua conta Claude
codex login    # ou entre com a sua conta do Codex
4

Confira uma resposta real

Usa o mesmo código do app e o login do Claude Code para pedir uma resposta de verdade (modelo haiku, o mais leve). Grava o resultado em kit/verificacao/ultima-resposta.json. Este teste é só para o Claude.

node kit/scripts/conferir-resposta.mjs   # "Login do Claude: OK (assinatura claude.ai)"
5

Abra o app

Abre a instância "principal". No Linux, se aparecer o aviso de sandbox desligado, o app funciona assim mesmo; veja como ligar em COMO-LIGAR-SANDBOX.md.

kit/iniciar.sh
6

Escolha o provedor e crie o primeiro bot

No app, vá em Settings → AI subscription, escolha Claude ou Codex e crie o primeiro bot no botão +. O app já vem com um bot "Assistente" que responde em português.

7

(Opcional) Abra um segundo time

Instância é uma cópia separada do app, com bots, conversas e memória próprios. O nome aceita letras, números, - e _.

kit/iniciar.sh --instancia trabalho   # dados em ~/.local/share/time-de-bots/trabalho

Numa VPS (ligado 24 h)

8

Baixe o kit em ~/time-de-bots

Entre no servidor por SSH com um usuário comum que tenha sudo (não root). O serviço espera o kit exatamente nesta pasta.

git clone https://github.com/inematds/time-de-bots.git ~/time-de-bots && cd ~/time-de-bots
9

Prepare o servidor

Instala a tela virtual, o VNC e o noVNC (programas que mostram essa tela no seu navegador) e as bibliotecas do app (com sudo), instala o Node 22 se faltar, deixa os serviços rodando depois que você sai do SSH e roda o kit/instalar.sh. Não abre nenhuma porta no firewall. Na VPS, o sandbox também é ligado à parte, com os comandos de Cuidados.

kit/vps/instalar-vps.sh
10

Entre na sua conta pelo SSH

O instalar-vps.sh não instala o Claude Code nem o Codex: instale no servidor o que for usar (Claude Code pelo guia de instalação; Codex com sudo npm i -g @openai/codex). No servidor não há navegador; no Codex, use o login por código de dispositivo.

claude                       # conta Claude
codex login --device-auth    # ou conta do Codex
11

Ligue a primeira instância

Cria o serviço time-de-bots@principal, que sobe sozinho e reinicia se cair (até 2 GB de memória por instância). No fim, imprime o comando do túnel.

kit/vps/nova-instancia.sh principal 1   # tela :21, VNC 5921, navegador 6081
12

Abra pelo navegador, via túnel

O túnel SSH leva uma porta do servidor até o seu computador por dentro da conexão SSH, sem abrir nada para a internet. No seu computador, copie o comando que o nova-instancia.sh imprimiu (ou troque usuario@servidor pelo seu usuário e o IP da VPS) e deixe o terminal aberto. Depois, no navegador, entre no endereço e clique em Connect.

ssh -N -L 6081:127.0.0.1:6081 usuario@servidor
# no navegador:
http://localhost:6081/vnc.html
13

(Opcional) Segundo time na VPS, ou desligar

O número (1 a 50) define a tela e as portas: com 2, o navegador fica na porta 6082.

kit/vps/nova-instancia.sh trabalho 2                # túnel e navegador na porta 6082
systemctl --user disable --now time-de-bots@principal   # desliga uma instância

Com o app já aberto: o assistente pergunta sobre o seu trabalho e propõe 3 bots prontos para copiar.

Cuidados

Antes de usar no dia a dia

Software experimental, sem garantia. Teste primeiro com uma instância descartável.

🔑 Só assinatura

O app só aceita o login claude.ai do Claude Code ou o login do Codex. O kit/iniciar.sh remove ANTHROPIC_API_KEY, OPENAI_API_KEY e CODEX_API_KEY do ambiente, para nada ir para cobrança por API sem você ver.

📏 Limites continuam

A assinatura tem limites de uso e termos do provedor. O painel não aumenta isso: vários bots usam a mesma cota.

🙋 O login é seu

Nunca cole token ou senha no chat do assistente. O login é feito por você, no terminal.

🔒 VPS fechada

VNC e navegador ouvem só em 127.0.0.1. Você entra por túnel SSH; nada fica aberto para a internet.

🧱 Sandbox no Linux

O sandbox do Electron é uma proteção que separa as telas do app do resto do sistema; sem ele o app abre igual, só com menos proteção. Para ligar (uma vez, depois de cada npm ci), com sudo:

cd app/node_modules/electron/dist
sudo chown root:root chrome-sandbox
sudo chmod 4755 chrome-sandbox

💾 Backup

Antes de atualizar, copie a pasta de dados ~/.local/share/time-de-bots/. Lá ficam bots, conversas e memória de cada time.

FAQ

Perguntas rápidas

O essencial em poucas linhas.

Preciso de chave de API ou pagar por uso?

Não. O app responde pela sua assinatura do Claude ou do Codex, com o login do programa oficial. As chaves de API são tiradas do ambiente antes de abrir.

As tarefas agendadas rodam com o computador desligado?

Não. Elas só rodam com o app aberto. Para ficarem ligadas 24 h, use o modo VPS.

Posso ter mais de um time?

Sim. Cada --instancia (no computador) ou cada nova-instancia.sh (na VPS) é um time separado, com dados próprios.

Como chamo vários bots numa conversa?

Numa conversa em grupo, chame pelo nome com @nome, ou todos com @everyone.

O Codex funciona?

O Codex é uma das opções em Settings → AI subscription, mas a resposta real pelo Codex ainda não foi testada (veja a tabela). O teste de resposta do kit confere só o Claude.

Por que aparece "sandbox do Electron desligado"?

No Linux, o sandbox precisa de um ajuste com sudo. Sem ele o app abre igual, com menos isolamento. Os comandos estão em Cuidados.
