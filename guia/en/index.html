In short

Time de Bots ("Team of Bots" in Portuguese) is a free INEMA kit that installs a bot dashboard on your Linux or Mac computer, or on a VPS (a server you rent on the internet). Each bot has a name, avatar, role, memory and scheduled tasks, and you chat with one at a time or with several in a group. The replies come from your Claude or Codex subscription, through the normal login of the official program, with no API key and no pay-per-use billing. You need Node.js 22 or newer and a Claude account or a ChatGPT account with Codex.

What it is

A bot app + a kit that installs, checks and starts it

The bot app is a desktop program (built with Electron, MIT license). The INEMA kit gets that app running the right way: it installs it, runs the tests, opens several teams and sets up server mode.

🔑 Only your subscription

The app only accepts the Claude Code claude.ai login or the Codex login. kit/iniciar.sh removes the API keys from the environment before opening.

🧑‍🤝‍🧑 Bots with a role

Each bot has a name, avatar, instructions, memory and scheduled tasks. Chat with one or call several together in a group.

🗂️ Several teams

Each instance is a separate team, with its own bots, chats and memory. E.g.: a personal one and a work one on the same machine.

How it works

From your subscription to the bot group

You log in to your account once, in the terminal. The app uses that login to reply. The bots live in the dashboard, chat on their own or in a group and run tasks at the scheduled time.

Your Claude or Codex subscription→ Login in the terminal (claude / codex login)→ Time de Bots app→ Bots · group · schedule

💻 On your computer

The app opens in a window, like any program. Each team's data lives in ~/.local/share/time-de-bots/<instance>.

🖥️ On a VPS, over an SSH tunnel

The server creates a virtual screen and shows the app in the browser (noVNC), all bound to 127.0.0.1. You open an SSH tunnel from your computer and go to http://localhost:6081/vnc.html. No port is left open to the internet.

User guide · step by step

From zero to your first bot

Real kit commands. Run them in the terminal, in the kit folder. Would you rather have the assistant do it for you? Skip to the ready-made prompts.

On your computer

1

Download the kit

Downloads the repository and enters the folder.

git clone https://github.com/inematds/time-de-bots.git && cd time-de-bots
2

Install and run the tests

Checks Node and npm, installs the dependencies, downloads the app files (verified by checksum) and runs the 193 tests. It doesn't log in to any account.

kit/instalar.sh   # at the end: "[ok]  193 testes passaram"
3

Log in to your account (once)

You do the login yourself in the terminal. The claude command opens Claude Code: the first time, it asks you to sign in to your account; once signed in, leave with /exit. Don't have Claude Code yet? See the installation guide. Use one of the two:

claude         # log in with your Claude account
codex login    # or log in with your Codex account
4

Check a real reply

Uses the same code as the app and the Claude Code login to ask for a real reply (haiku model, the lightest one). Saves the result in kit/verificacao/ultima-resposta.json. This test is for Claude only.

node kit/scripts/conferir-resposta.mjs   # "Login do Claude: OK (assinatura claude.ai)"
5

Open the app

Opens the "principal" instance. On Linux, if you see the sandbox-disabled warning, the app works anyway; see how to enable it in COMO-LIGAR-SANDBOX.md (in Portuguese).

kit/iniciar.sh
6

Choose the provider and create your first bot

In the app, go to Settings → AI subscription, choose Claude or Codex and create your first bot with the + button. The app already comes with the "Assistente" (Assistant) bot, which replies in Portuguese.

7

(Optional) Open a second team

An instance is a separate copy of the app, with its own bots, chats and memory. The name accepts letters, numbers, - and _.

kit/iniciar.sh --instancia trabalho   # data in ~/.local/share/time-de-bots/trabalho

On a VPS (running 24/7)

8

Download the kit to ~/time-de-bots

Log in to the server over SSH with a regular user that has sudo (not root). The service expects the kit in exactly this folder.

git clone https://github.com/inematds/time-de-bots.git ~/time-de-bots && cd ~/time-de-bots
9

Prepare the server

Installs the virtual screen, VNC and noVNC (programs that show that screen in your browser) and the app libraries (with sudo), installs Node 22 if missing, keeps the services running after you leave SSH and runs kit/instalar.sh. It doesn't open any port in the firewall. On the VPS, the sandbox is also enabled separately, with the commands in Cautions.

kit/vps/instalar-vps.sh
10

Log in to your account over SSH

There's no browser on the server; for Codex, use the device-code login.

claude                       # Claude account
codex login --device-auth    # or Codex account
11

Start the first instance

Creates the time-de-bots@principal service, which starts on its own and restarts if it crashes (up to 2 GB of memory per instance). At the end, it prints the tunnel command.

kit/vps/nova-instancia.sh principal 1   # screen :21, VNC 5921, browser 6081
12

Open it in the browser, through the tunnel

The SSH tunnel brings a server port to your computer through the SSH connection, without opening anything to the internet. On your computer, copy the command that nova-instancia.sh printed (or replace usuario@servidor with your user and the VPS IP) and leave the terminal open. Then, in the browser, go to the address and click Connect.

ssh -N -L 6081:127.0.0.1:6081 usuario@servidor
# in the browser:
http://localhost:6081/vnc.html
13

(Optional) Second team on the VPS, or shut down

The number (1 to 50) sets the screen and the ports: with 2, the browser is on port 6082.

kit/vps/nova-instancia.sh trabalho 2                # tunnel and browser on port 6082
systemctl --user disable --now time-de-bots@principal   # shuts down an instance

Run it on the server, already connected over SSH. Prepares everything, starts the instance and checks that the ports are closed.

3 · Build my first team

With the app already open: the assistant asks about your work and proposes 3 ready-to-copy bots.

First ask me: what my job is and which 3 repetitive tasks I'd most like to take off my plate. With the answers, propose 3 bots. Cautions

Before using it day to day

Experimental software, no warranty. Test first with a throwaway instance.

🔑 Subscription only

The app only accepts the Claude Code claude.ai login or the Codex login. kit/iniciar.sh removes ANTHROPIC_API_KEY, OPENAI_API_KEY and CODEX_API_KEY from the environment, so nothing gets billed through the API without you noticing.

📏 Limits still apply

The subscription has usage limits and the provider's terms. The dashboard doesn't raise them: several bots share the same quota.

🙋 The login is yours

Never paste a token or password into the assistant's chat. You do the login yourself, in the terminal.

🔒 Closed VPS

VNC and the browser listen only on 127.0.0.1. You get in through an SSH tunnel; nothing is left open to the internet.

🧱 Sandbox on Linux

The Electron sandbox is a protection that separates the app's screens from the rest of the system; without it the app opens the same, just with less protection. To enable it (once, after each npm ci), with sudo:

cd app/node_modules/electron/dist
sudo chown root:root chrome-sandbox
sudo chmod 4755 chrome-sandbox

💾 Backup

Before updating, copy the data folder ~/.local/share/time-de-bots/. That's where each team's bots, chats and memory live.

FAQ

Quick questions

The essentials in a few lines.

Do I need an API key or to pay per use?

No. The app replies through your Claude or Codex subscription, with the login of the official program. API keys are removed from the environment before opening.

Do scheduled tasks run with the computer off?

No. They only run with the app open. To keep them running 24/7, use VPS mode.

Can I have more than one team?

Yes. Each --instancia (on the computer) or each nova-instancia.sh (on the VPS) is a separate team, with its own data.

How do I call several bots in one chat?

In a group chat, call them by name with @name, or all of them with @everyone.

Does Codex work?

Codex is one of the options in Settings → AI subscription, but the real reply through Codex hasn't been tested yet (see the table). The kit's reply test only checks Claude.

Why does "Electron sandbox disabled" show up?

On Linux, the sandbox needs a tweak with sudo. Without it the app opens the same way, with less isolation. The commands are in Cautions.
